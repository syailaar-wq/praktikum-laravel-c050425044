# Praktikum Laravel C050425044

## Deskripsi Proyek

Proyek ini dibuat untuk memenuhi tugas Praktikum Pemrograman Berbasis Web menggunakan framework Laravel. Aplikasi digunakan sebagai media pembelajaran mengenai migration, model, seeder, factory, routing, dan fitur dasar Laravel lainnya.

## Teknologi yang Digunakan

- Laravel 13
- PHP
- MySQL
- Composer
- Git dan GitHub

## Cara Menjalankan Proyek

1. Clone repository

```bash
git clone <url-repository>
```

2. Masuk ke folder proyek

```bash
cd praktikum-laravel-c050425044
```

3. Install dependency

```bash
composer install
```

4. Jalankan migration dan seeder

```bash
php artisan migrate:fresh --seed
```

5. Jalankan server Laravel

```bash
php artisan serve
```

6. Buka browser

```text
http://127.0.0.1:8000 
```
